# Help Ross — Lumani Impact

Static page prepared from the supplied ZIP, with Help Ross as the homepage.

## Payments

The six USD amount buttons on `donate.html` link directly to the Stripe URLs supplied by the site owner. Stripe controls the final checkout amount, currency and recipient.

## Hosting

Publish the repository root with GitHub Pages (branch `main`, folder `/`). `.nojekyll` is included. No build or dependencies required.

## Data

Campaign text, totals, supporter counts and related campaigns are a snapshot from the supplied archive. They do not update from Stripe. The archive did not include the other institutional pages; those navigation links point to the original website. Images and media referenced by the campaign data are included locally. No private Stripe keys are required.
